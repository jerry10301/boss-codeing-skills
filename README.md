# Boss Coding Skills — 零基礎開發工具包

專為**沒有資訊背景**的人設計的 AI 開發技能組合包。
你只需要描述想要什麼，AI 會幫你把程式做出來、存好進度、隨時可以回到之前的版本。

---

## 包含哪些技能

| 技能檔案 | 功能 | 觸發方式 |
|---------|------|---------|
| `dist/boss-coding.skill` | **組合包**：開發 + 存檔 + 讀檔一次整合 | 直接描述需求、說「存檔」、說「讀檔」 |
| `dist/vibe-coding.skill` | 單獨使用開發功能 | 描述你想要什麼 |
| `dist/git-save.skill` | 單獨使用存檔功能 | `/存檔`、`存檔` |
| `dist/git-load.skill` | 單獨使用讀檔（還原版本）功能 | `/讀檔`、`讀檔`、`回到之前` |

### 開發流程技能（逐步引導版）

| 技能檔案 | 功能 | 觸發方式 |
|---------|------|---------|
| `dist/discuss.skill` | 自由討論、腦力激盪，探索想法 | `/討論` |
| `dist/gather-requirements.skill` | 收斂討論，整理成需求清單 | `/整理需求` |
| `dist/confirm-tasks.skill` | 產出規格與工項清單，等使用者確認才動工 | `/確認工項` |
| `dist/start-implement.skill` | 照著確認的計劃開始實作 | `/開始實作` |
| `dist/auto-test.skill` | 執行自動測試，驗證功能正常 | `/自動測試` |
| `dist/code-check.skill` | Code review，找出潛在問題 | `/檢查程式` |

> **建議**：直接安裝 `boss-coding.skill` 就夠了，已包含全部功能。
> 想要更結構化的開發流程，可以另外安裝開發流程技能。

---

## 安裝方式

1. 點選上方你要的 `.skill` 檔案
2. 按右上角 **Download raw file** 下載到電腦
3. 在 Claude Code 中，把 `.skill` 檔案**拖曳進對話視窗**即可安裝

---

## 使用方式

安裝 `boss-coding.skill` 後，直接在 Claude Code 對話中說：

- **「我想做一個記帳表格」** → AI 直接幫你做出來
- **「幫我做一個客戶問卷頁面」** → AI 做好後讓你看結果
- **「存檔」** → 記錄目前的進度
- **「讀檔」** → 列出所有版本，選一個回到那個時候
- **「怎麼用」** → 顯示完整使用說明

全程不需要打任何指令，不需要懂程式。

---

## 設計理念

這個工具包把你定位為**老闆**，AI 是**工具師傅**。

老闆描述需求，師傅把東西做出來。師傅不會叫老闆自己去操作機器、理解工具原理、或是複製貼上程式碼。事情做完，老闆驗收就好。
